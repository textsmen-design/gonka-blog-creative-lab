# Админка GONKA.BLOG

Рабочая админка находится по адресу https://admin.gonka.blog. Локальный вариант запускается командой `npm run admin` на `127.0.0.1:4310`. Пароли, токены, их хеши и журнал не включаются в Git.

## Как опубликовать изменения

1. Выберите раздел, внесите изменения и нажмите «Сохранить черновик». Если данные уже изменены в другом окне, сначала перезагрузите их и проверьте изменения.
2. Нажмите «Опубликовать» и дождитесь подтверждения. После этого проверьте сайт.
3. Запись с будущей датой появится только после новой публикации, выполненной в эту дату или позднее.

## Большая книга

- «Новости — левая страница»: добавляйте записи NewGonkaLab, указывайте название, текст, дату и отметку публикации. Можно указать HTTPS-ссылку на материал и ссылку на видео. YouTube отображается внутри новости; другие HTTPS-ссылки открываются отдельно.
- К записи можно прикрепить один файл: PNG/JPEG/WebP до 2 МБ или MP4/WebM/PDF до 25 МБ. Загрузите файл, сохраните черновик, затем опубликуйте сайт. Загрузка файла сама по себе ещё не публикует запись.
- «Истории — правая страница»: редактируйте заголовки, абзацы и мораль, добавляйте и удаляйте истории. После публикации автоматическое перелистывание сохранится. Нужна хотя бы одна история.

Изображения и другие вложения новостей хранятся в `public/news-media`. Экспорт данных из админки не является резервной копией этих файлов.

## Проверки и публикация кода

`npm test`, `npm run check:bindings` и `npm run verify:dist` проверяют данные, привязки и сборку. `npm run build` создаёт статический каталог `dist`. Для серверного деплоя, резервных копий и отката см. `DEPLOY.md` в корне проекта.
