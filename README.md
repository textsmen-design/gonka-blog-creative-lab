# GONKA.BLOG — Личная цифровая лаборатория

**GONKA.BLOG** — интерактивное цифровое пространство-лаборатория, спроектированное в виде визуального светового верстака (Drafting Table / Workbench). 

Здесь представлены готовые веб-проекты, Telegram-боты, AI-инструменты, исследования, закрытые гипотезы и конвейер стадий разработки цифровых продуктов.

---

## 🏛 Концепция

- **Стол и предметы** — основная визуальная часть сайта. Пользователь может свободно исследовать верстак, взаимодействовать с физическими предметами (блокнот, свитки, телефон, киноплёнка, звёздная карта, кружка, открытка).
- **Правое вертикальное меню (Оглавление стола)** — консервативная альтернативная навигация, состоящая из 8 единообразно оформленных пунктов:
  1. `ЧЕРНОВИК` → лабораторный эскиз и записи первого листа
  2. `ЛЕНДИНГИ` → каталог действующих веб-проектов лаборатории (English Teacher, TwoHearts, Siteviza, Atelier, LandAsset5, Tracker_01)
  3. `СИСТЕМА` → архитектурное ядро и схема связей GONKA.BLOG
  4. `МЯСНАЯ ТРОИЦА` → досье действующего Telegram-бота мониторинга цен на мясо
  5. `НЕ ПОШЛО` → архив закрытых гипотез и разобранных ошибок
  6. `ВИДЕО` → монтажный стол и киноплёнка рабочего процесса
  7. `ИНСТРУМЕНТЫ` → стек технологий, карта связей и инфраструктура
  8. `БОТЫ` → каталог Telegram-ботов лаборатории (Мясная Троица и Бот Детектив)
- **Предметы на столе остаются интерактивными точками входа**:
  - Красный телефон прямой связи (`modal-incoming`)
  - Интерактивный свиток ботов со смартфоном и кнопками быстрого открытия досье
  - Открытка «Релокант Сербия» (прямой переход на `https://reloca.gonka.blog/`)
  - Кружка-манифест «IDEAS BUILD TEST REPEAT» (`modal-manifesto`)
  - Свиток «АВТОР» («Хорошие идеи приходят не по расписанию») (`modal-about`)

## 🚀 Быстрый запуск

Требования: **Node.js >= 22.12.0**

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки (http://localhost:4321)
npm run dev

# 3. Сборка production-версии в папку ./dist/
npm run build

# 4. Локальный просмотр production-сборки
npm run preview
```
