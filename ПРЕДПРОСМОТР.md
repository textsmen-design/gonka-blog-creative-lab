# GONKA.BLOG 2.0 — предпросмотр

Версия 2.0 опубликована на https://gonka.blog. Эта папка может отставать от действующего сайта: новости, истории и вложения могут изменяться через админку на сервере. Перед новой публикацией сверьте контент и файлы с сервером.

Локальный запуск: `npm install`, затем `npm run build` и `npm run preview`. Для разработки используйте `npm run dev`. Требуется Node.js не ниже 22.12.0.

В большой книге слева находятся новости NewGonkaLab, справа — истории с автоматическим перелистыванием. Записи редактируются в админке. Публичные записи выбираются при сборке, поэтому для появления записи с будущей датой после наступления даты потребуется новая публикация.

Перед очередным деплоем проверяйте отображение и управление на компьютере и телефоне, обе темы, ссылки, вложения и админку. Актуальный порядок публикации и отката описан в `DEPLOY.md`.
