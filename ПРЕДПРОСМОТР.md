# GONKA.BLOG 2.0 — рабочий предпросмотр

Это отдельная копия исходного проекта. Публичный сайт не менялся.

Запуск: дважды нажмите «Открыть предпросмотр.command» в папке уровнем выше. Адрес: http://127.0.0.1:4352/. Остановка — Ctrl+C или закрытие окна Terminal. После изменений исходников перед запуском выполните в папке проекта `npm run build`.

Большая книга открывает раздел «Новость дня». Пока опубликованных новостей нет, отображается нейтральная заглушка. Данные находятся в `src/data/news.json`; для работы требуется у записи `published: true`, дата `date` в формате YYYY-MM-DD, `title`, `summary` и необязательная ссылка `url` по HTTPS. Показ выбирается при сборке; создание, проверка актуальности и автоматическое получение новостей пока не подключены. После изменения данных нужна новая сборка. Не публикуйте непроверенные новости.

Визуал ночного режима пока основан на затемнённом дневном фоне. До деплоя требуется полноценная проверка на компьютере и мобильном устройстве, в том числе анимаций, расположения предметов, свитков, всех ссылок, админки, скорости и тем. В среде сборки сетевой сервер и Chrome запустить не удалось.
